Import and export

    File format

    A two-column .tsv file - what the KOReader plugin writes and Anki imports. Importing adds phrases this pair is missing and never touches a saved one. In the meaning cell, a semicolon followed by a space separates meanings; a semicolon without a space stays inside its meaning. Export for Anki writes a third column with the sentence each phrase was saved in - empty when none was kept. That file can be imported back too: its sentences come along, and a phrase already saved takes the file's sentence only when it has none of its own.
